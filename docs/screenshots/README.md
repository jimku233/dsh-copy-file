# 截图说明

这个目录目前有两张：**`01-menu.png`**（菜单，已裁到只剩三项）和 **`02-success.png`**（复制路径成功的 toast）。第三张降级提示还需要补拍，规则如下。

## 为什么

作者本地的截图是用 CDP 直接截真实 DSH 界面得到的，画面上会包含：

- 个人主目录路径（`C:\Users\<你的用户名>\...`）
- 工作区名与会话标题
- 交付文件的真实文件名

这些都不该进开源仓库。所以这里只放"怎么截"，不放图片。

## 怎么截（建议用示例文件）

1. 在工作区建两个**中性**示例文件，例如
   `示例 报告.md`（中文名 + 空格）和 `示例 second file.txt`；
2. 让模型对它们各调用一次 `present`；
3. 截 4 张图，建议只截局部（Windows `Win+Shift+S`）：

| 文件名 | 截什么 | 注意 |
|---|---|---|
| `01-menu.png` | 已完成（裁到只剩三行菜单） | — |
| `02-toast.png` | 复制成功后的 toast（1.5 秒内） | 先确认 toast 里的文件名是示例文件名 |
| `03-degrade.png` | 把示例文件改名后再点复制，出现的降级提示 | 同上 |
| `04-drag.png` | 拖拽时跟随鼠标的 ghost | 别把侧栏会话标题截进去 |

4. 保存到本目录，README 里再引用。
